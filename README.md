# Мои задачи

Список дел на Next.js. Можно добавлять и менять задачи, отмечать выполненные, удалять и искать. Есть фильтры по категории и статусу.

Данные сохраняются в localStorage этого браузера. Примеры задач находятся в `data/tasks.js`.

## Запуск

```
npm install
npm run dev
```

Открыть http://localhost:3000.

Сборка: `npm run build`. Готовый сайт находится в `out`.
